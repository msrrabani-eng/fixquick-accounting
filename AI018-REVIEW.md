## Engine and speech
Native Capacitor plugin Java + JNI C++ implementation. `tools/install_local_ai.py` installs the bridge into the generated Android project, pins upstream llama.cpp `b6500` commit `a7a98e0fffed794396b3fbad4dcdbbc184963645`, sets NDK/CMake versions and registers native plugin. Native engine built for ARM64; other standard ABIs get placeholder libraries, basic app remains available. Model uses CPU and 4096-token bounded context, 512 generated tokens by default, model/context freed after each request to reduce idle memory. No API key or online inference. Qwen prompt uses the Qwen3 chat format, non-thinking mode; structured outputs restricted to query, finance, clarify, advice. Actual numbers calculated by permission-gated existing engines; hypothetical calculations require confirmation. General advice is clearly labeled unverified. No automatic ledger writes. Native software is not sandboxed against arbitrary hostile other apps or OS compromise; only official model permitted by checksum.
Speech uses Android on-device SpeechRecognizer API >=31 (fa-IR), only when available; text is placed in the input, not auto-sent. Offline Persian TTS voices are chosen only when installed. Not all Android devices support Persian locally; Qwen itself is a text model, not a speech recognizer. Offline voice availability/quality on Nothing Phone 2a unverified; no automatic online speech fallback.
